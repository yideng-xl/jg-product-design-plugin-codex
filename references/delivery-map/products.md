# 产品差异配置

两个入口共用流程。此处集中列出路径、字段、视图和配置读取方式，实际文件名和规则以产品目录为准。

| 项目 | 集管 | 网管 |
|---|---|---|
| Skill | `update-delivery-map-jg` | `update-delivery-map-wg` |
| 检查参数 `--product` | `集管` | `网管` |
| 常见产品目录 | `10-productDocs/01-集管/30-产品交付进度/` | `10-productDocs/02-网管/30-产品交付进度/` |
| 地图文件 | `集管产品交付地图.html` | `网管产品交付地图.html` |
| 地理骨架 | `集管项目进度表_按调度体系.xlsx` | `网管项目进度表_按调度体系.xlsx` |
| 项目登记表 | `集管产品项目进度表.xlsx` | `网管产品项目进度表.xlsx` |
| 骨架工作表 | `国网三级调度`、`超高压` | `国网三级调度` |
| 地区列 | `地区` | `区域` |
| 补充字段 | `标杆项目` | 按实际表头检查，可能有独立的 `分类` 列 |
| 地图视图 | 合并、超高压、分部、省调、地调，共 5 个 | 合并、分部、省调、地调，共 4 个 |
| 数据源配置 | 当前生成模板或产品目录本地配置 | 当前 `delivery-map-policy.json` 中的 `source_url`、`source_label` |
| 发布文件 | `交付地图/集管产品交付地图.html` | `交付地图/网管产品交付地图.html` |

数据源的具体地址始终留在产品工作区。两条产品线分别读取各自配置，不复制另一产品的链接、别名、地理落点或状态规则。这里描述现有配置位置，维护 skill 时无需迁移产品脚本。

## 已确认的页面范围

- 集管：保留顶部“交付版本、中间件等细节”入口。地图输入为月度进度表与调度骨架，不读取《集管信息一览表》，不添加环境明细、环境统计、筛选或导出。
- 网管：项目核对依据保存在本地，不展示“本期项目明细与覆盖依据”，生成模板中也不保留指向该区块的提示。

## 产品目录中的历史与状态配置

集管已有合并项目跨省调、地调或超高压的多行映射，更名和新落点以当前脚本中的显式配置为准。网管已存在本地项目分类、别名、非调度客户、历史基线及核对记录；其存储方式和已确认的状态判定保留。

基础状态规则见 [数据规则](data-rules.md)。实际产品可能已经确认“完成”“取消”或“升级”的处理方式；读取当前配置及依据后执行，不把一条产品线的例外直接推广给另一条。
