退回任务

状态与异常

待开始 → 进行中 → 待验收 → 已完成；待验收可退回进行中。前置未完成、验收未完成、访客操作均不能改变任务状态。状态改变后再次操作时，按最新状态重新校验。

编辑范围

待开始、进行中允许修改任务名称、负责人、优先级和截止日期。待验收、已完成只能查看。任务名称与日期沿用新建校验；任务验收要求和前置关系创建后只读。编辑取消不保存；离开未保存表单前需确认。

验收条件

完成会写入一条操作记录并重算项目进度。按钮禁用说明与执行时校验使用相同规则。界面角色限制仅用于演示，正式系统需在服务端验证权限。

R-04 · 操作与状态

管理员可处理任务，访客只读。已完成任务不再编辑或退回。开始任务、提交验收会记录操作者、时间和状态变化。

R-06 · 完成前逐项核对

仅待验收任务开放勾选。全部验收项通过后才能标记完成；仍有未核对项时禁用完成按钮并给出原因。

R-07 · 操作记录

创建、编辑、开始、提交验收、退回和完成分别记录。退回原因保存到记录；退回时清空验收勾选，重新提交后再核对。

R-06 · 退回必须说明原因

原因去除首尾空格后为 1–300 字。取消不改任务；确认后回到进行中，历史记录保留。

演示设置

操作只保存在当前浏览器，不会发送到服务器。此区域用于体验不同角色和主题。

界面主题

恢复会清除本 Demo 中新增的项目、任务和操作记录，其他站点数据不受影响。
