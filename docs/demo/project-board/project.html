跨页面规则

点击任务进入只读详情；修改操作单独进入编辑态。返回项目时保留项目标识。前置关系在新建时确定，已创建任务不提供修改前置关系的入口。

字段填写方式 / 必填类型 / 长度校验与数据来源关联关系
任务名称输入 / 是文本 / 50 字去首尾空格，项目内不重名项目内唯一

R-01 · 实时汇总

项目详情与首页使用同一份任务数据。任务完成后，两处进度、风险和统计同步变化；任务记录仍保留。

R-04 · 任务的流转条件

待开始任务仅在前置任务完成后才能开始。进行中可提交验收；待验收可退回进行中，或核对全部验收项后完成。已完成任务为只读终态。

R-05 · 新任务的初始状态

创建后状态为待开始，进度重新计算。已完成项目允许新增任务，新增后项目自动变为进行中。

R-05 · 日期与前置任务

任务截止日期不早于当天且不晚于项目截止日期。前置任务只从当前项目选择。新任务不能依赖自身；任务名称在当前项目内唯一。
