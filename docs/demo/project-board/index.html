R-01 · 进度从哪里来

项目进度 = 已完成任务数 ÷ 全部任务数，四舍五入到整数。没有任务时显示 0%，状态为待启动。统计卡始终统计全部项目，不随下方筛选变化。

R-02 · 组合查询

名称包含匹配；负责人、状态精确匹配。条件取交集。查询与重置后回到第 1 页，卡片和列表共用相同结果。

R-03 · 创建权限

只有项目管理员可以新建项目。访客入口禁用；切换角色后，已经打开的编辑表单关闭。

R-03 · 创建前校验

名称去除首尾空格后为 1–50 字，不能与现有项目重名；负责人必选，目标为 1–300 字，截止日期不能早于当天。校验失败保留输入。
