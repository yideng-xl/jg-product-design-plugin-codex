# 数据规范 v1.0

## 数据合同与分层

接入时记录下列项目。缺少业务口径时标“待确认”，继续能独立开展的检查。

| 项目 | 必须明确的内容 |
|---|---|
| 来源 | 文件或库表、工作表/命名表、表头位置、导出批次、源时间范围 |
| 粒度 | 一行代表工单版本、工单、资产、日志事件还是关联候选 |
| 身份 | 原始记录主键、业务编号、来源序号；编号不唯一时不能称为主键 |
| 字段 | 原字段、类型、单位、状态值、时间格式和时区；标识优先文本，保留前导零 |
| 关联 | 关联字段、方向、预期基数、唯一/多候选/未关联处置 |
| 更新 | 覆盖或追加、结构要求、全部连接映射、刷新方式 |
| 分析 | 状态范围、日期依据、去重范围、阈值、分母和排除项 |

原始层保留全量源记录、源字段和原值，不加计算列、不联接放大、不静默删除重复项。分析层创建标准化、分类、关联和统计，新增计算及参数统一 `分析-` 前缀。源表本身有同名前缀时登记来源，不仅凭名称认定为新增字段。

Excel 不预先写入分析列。格式确有问题时保留原件、说明修复项并确认未改变业务值。读取不到行时先查表头、工作表范围、类型和命名表引用，避免用分析结果替换源数据。

## 关联与计数

不同粒度的表优先评估 Tableau 逻辑关系；需要固定联接语义时使用物理联接，并核验行数影响。任何方式均须抽样回查，建模方式本身不能证明结果正确。

- 工单记录数、去重工单数、日志事件数、关联候选数分别命名。
- 日志与多个工单匹配时保留所有候选，单列候选数量，不任取第一张。未匹配日志保留核对入口。
- 无直接工单 ID 时，名称、站点、负责人或时间窗按已验证口径生成候选；同名、同序号不直接证明同一对象。
- 关联覆盖率分别报告唯一匹配、多候选、未匹配，分母为原始日志事件数。联接后的行数不作事件数。
- 有日志 ID 时按 ID 核验；无 ID 时登记来源文件、表与源记录标识。不直接合并内容相同的多次事件。
- 一对多展开后不得把重复出现的工单时长作为多个样本参与中位数。先在工单样本粒度计算，再关联展示。

去重只作用于明确的分析范围，原始层与重复编号核对表保留全部记录。沿用工单时长基线时：同编号实际起止齐全优先；同样齐全时原始序号最小优先。缺少稳定序号或出现同序号并列时先明确来源次序，不能随刷新随机取一条。

## 时间与筛选

区分计划起止、实际起止和日志产生时间，统一时区。时间差注明秒、分钟或小时，NULL 不转成零时长。

| 口径 | 条件 |
|---|---|
| 区间包含 | 工单开始不早于起点，工单结束不晚于截止 |
| 开始日期 | 所选开始字段落在范围内 |
| 区间相交 | 工单区间与筛选区间存在交集 |
| 日志时间 | 日志产生时间落在范围内 |

三种工单时间口径不混用，依据现有报告或用户选择设置。按日期包含截止日全天时使用 `时间 < 截止日期次日零点`。工单自身时间倒置与筛选输入倒置分别提示。

共享参数不等于全部数据源已应用筛选：为相关源设置对应筛选字段，核对使用范围。说明日志时长是基于筛选后日志还是工单全部日志，两者不悄悄替换。

FIXED LOD 通常先于普通维度筛选执行。分类基准需随日期或状态变化时，把相应筛选加入上下文，或把样本条件写入计算，逐表核验。基准刻意固定时在说明中声明。

## 字段与参数登记

| 名称 | 原始/计算/参数 | 来源或公式 | 粒度 | 单位 | 空值/异常处理 | 默认值及范围 |
|---|---|---|---|---|---|---|
| 原始字段名 | 原始 | 源表与字段 | 记录 | 按源数据 | 保留 | 无 |
| 分析-指标 | 计算 | 可执行公式 | 工单/日志 | 小时等 | 明确排除项 | 按说明 |
| 分析-阈值 | 参数 | 用户可调 | 当前分析 | 同指标 | 校验上下界 | 项目确认值 |
