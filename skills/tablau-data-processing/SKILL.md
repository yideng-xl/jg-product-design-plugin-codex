# tablau数据处理流程

基础版本：1.0。显示名称保留用户约定的 `tablau`；软件与文件格式使用 Tableau 正式名称。

## 数据源选择

| 输入 | 工作方式 | 交付与更新 |
|---|---|---|
| Excel | 保留 Excel 原生连接定义，使用数据提取；原始数据与分析逻辑分层 | Hyper 内置于 TWBX；打开不依赖外部 Excel；更新时在 Tableau 重新连接或刷新提取、保存 TWBX |
| 数据库 | 实时连接；计算字段和关联留在 Tableau 数据模型 | 依赖数据库、网络、驱动及使用者权限；TWBX 不会使实时数据库离线可用 |
| 混合来源 | 分别登记每个连接的模式和更新时间 | 明示哪些可离线、哪些必须联网 |

数据库要求离线分享时，说明与实时模式的区别，确认是否另交快照版本；不要擅自停库或切换模式。

## 执行顺序

1. 确认目标工作簿、来源、更新方式和业务问题。读取现有字段、工作表说明、参数和公式，保留人工修改；修改前保存可回退副本。
2. 按 [数据规范](references/data-standard.md) 登记字段、粒度、主键、重复项、关联依据与时间口径。原始表保留源记录，不将预先算好的分析结果冒充原始数据。
3. 建原始层与分析层。原始数据源命名 `原始·主题`，分析数据源命名 `分析·主题`；新增计算字段和参数统一 `分析-` 开头。分析层使用 Tableau 原生关系、联接、并集、计算字段和参数，更新后能够重新执行。
4. 按 [分析与工作表方法](references/worksheet-methods.md) 先做单主题，再按业务问题做跨主题分析。每个问题明确分母、范围、公式、阈值、证据和待确认事项；没有证据的推测标为候选。
5. Excel 建立提取并保存 TWBX，按 [更新与交付核验](references/refresh-and-delivery.md) 检查包内数据、全部受影响连接、刷新结果和独立打开。数据库核验实时模式、权限和查询结果。
6. 交付目标文件、更新入口、结果页签、口径说明和核验结论。写清已核验部分与尚未核验部分，不把保存成功当作分析正确或更新链路通过。

## 约束

- 计算可以物化在分析层 Hyper 中，但定义必须能从原始连接在 Tableau 内重算。不得用一次性脚本生成的结果表替代更新链路，也不把本地工具作为同事更新的前提。
- 原始字段保留名称与原值，标准化结果另建 `分析-` 字段。缺失、零值、不适用、未关联分别表达。
- 原始层与分析层可复用连接，也可分开建源；采用独立连接时登记全部引用位置，不能承诺更新一个原始源就会自动改变其他连接路径。
- 关联前确定粒度，关联后核对重复放大和未匹配记录。候选关系与唯一确认关系分别展示。
- 只打开本次目标工作簿进行界面核验，核对路径与标题，避免多个测试窗口混淆结果。
- 项目阈值、关键词和样本数不自动成为其他项目的事实。公开插件仅保留通用规则与虚拟示例，不包含业务记录、内部路径或凭据。
