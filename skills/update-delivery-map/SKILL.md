# 更新产品交付地图

本入口处理网管。集管任务转到同阶段的 [update-jiguan-delivery-map](../update-jiguan-delivery-map/SKILL.md)，读取月度进度并保留顶部详情链接；下文保留两条产品线的历史结构对照，供维护参考。

供产品负责人查看各调度层级的部署、试运行和运行覆盖情况。沿用产品目录内的地理骨架与地图模板，用月度跟踪表更新项目字段。

## 确定输入

先定位用户指定的产品目录、跟踪表和现有地图，读取目录中的说明与脚本。用户只指定一条产品线时，只更新这条线。工作区路径由当前环境确定，不依赖个人绝对路径。

| 文件 | 网管 | 集管 |
| --- | --- | --- |
| 常见目录 | `10-productDocs/02-网管/30-产品交付进度/` | `10-productDocs/01-集管/30-产品交付进度/` |
| 地图数据源 | `网管项目进度表_按调度体系.xlsx` | `集管项目进度表_按调度体系.xlsx` |
| 项目登记表 | `网管产品项目进度表.xlsx` | `集管产品项目进度表.xlsx` |
| 输出 | `网管产品交付地图.html` | `集管产品交付地图.html` |
| 视图 | 合并、分部、省调、地调 | 前述 4 个视图及超高压 |

文件名以实际目录和脚本为准。旧材料可能把集管 HTML 写成“覆盖地图”。截止月使用跟踪表对应月份，格式 `YYYY-MM`；不能用执行当天日期代替。文件名与表内统计口径冲突时询问用户。

本插件携带检查工具和更新方法。客户数据、地理骨架、地图模板及内网发布配置保留在产品工作区。缺少这些资源时先定位或请求补齐，不能仅凭月度表生成调度覆盖关系。

## 更新前检查

用含 `openpyxl` 的 Python 执行只读检查：

```bash
python <skill目录>/scripts/inspect_tracking.py <月度表.xlsx> --product 网管 --backbone <按调度体系.xlsx>
```

检查工具按表头读取，输出项目数、状态、重复键、新客户和历史未出现客户。不会写表，也不会自行认定新客户的地理归属。非零退出码表示存在缺列、空客户或重复客户冲突，应先处理。

读取 [字段、映射与状态规则](references/data-rules.md)，重点核对：

- 表头插列或重排。按列名匹配，网管“区域”和集管“地区”是同一类匹配字段。“分类”与“项目分类”分别读取。
- 重复客户、名称变化、一个项目对应多个调度行。不能用字典最后一条覆盖前面的记录。
- 新增客户和未再出现的历史客户。保留原客户证据，不自动删除历史覆盖。
- 升级项目、非调度客户、新状态。影响覆盖含义的规则先取得依据或用户确认，记录在产品目录。

## 合并与重建

1. 修改前备份会被覆盖的数据源、登记表、数据块、HTML 和相关脚本。已有 Git 仓库时核对工作区状态；保留用户未提交修改。
2. 复用产品目录的 `apply_monthly_update.py`。先检查它是否仍按固定列号读取；如表结构已变，先改成按表头读取并核对结果。只更新已有地理行的项目字段，不改变行政区划和调度关系。
3. 执行合并后逐项核对：本期项目均有去向；多行映射全部更新；登记表保留本期原始业务字段；缺失项目、历史保留、特殊客户及重复处理有记录。日志出现 `[需手工]`、漏项或字段错位时不能继续发布，退出码为 0 也不代表检查通过。
4. 使用产品目录所需的 Python 环境，在明确 `workdir` 的情况下执行 `update_map.py --date YYYY-MM`。它会调用 `convert_xlsx_to_js.py`、`rewrite_html_3maps.py`，更新 `data_block.js` 和 HTML，也会修改模板里的截止月。现有 HTML 中可能保存唯一的内嵌地理数据，重建前不要删除。
5. 打开 HTML，检查标题月份、覆盖统计、4 个或 5 个视图、典型项目提示和省内下钻；确认蒙西、南网排除显示正常，无脚本错误。至少抽查本期变动、新项目、历史保留各一例。无需因数据更新重做视觉设计。

无法判定的项目列明原因。用户明确同意按现有证据先发布时，在地图说明中保留相应范围限制。

## 发布与交付

读取 [预览站发布](references/publishing.md)。有当前发布授权时完成发布；用户只要求本地更新时停在本地。不要因使用本 skill 自动把客户资料推到插件仓库。

完成后给出可点击的地图链接、截止月、主要变化和尚未解决的事项。区分“本地生成”“已推送”和“线上内容已核验”；上线核验应比对实际 HTML 内容或 SHA-256，HTTP 200 不能证明部署的是本次版本。
