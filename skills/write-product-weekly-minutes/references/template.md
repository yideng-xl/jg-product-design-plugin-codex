# 产品部周例会输出模板

起草和修改使用 MD，用户确认后从最新 MD 生成最终 TXT，去掉 Markdown 标记及草稿后缀。下方是会前稿结构；已有用户修改稿时仅作局部修改，不重新套模板。会前情况写已确认结论，未知内容留空，现场补充留空；不预写主持核对、备选追问或串词。

- 产品方向、人员及有来源的本周计划按实际材料填写；成果和计划中的版本号及功能名保留。6 个章节及顺序不变。
- 整周及上半周、下半周不标日期；明确周几才加 `月.日` 括号日期，如“本周二（10.20）”。标题和栏目名不加日期。轮换规则见 [会议标准](meeting-standard.md)“人员培养及团队建设”。
- 会后依据逐字稿和用户明确修正填入结论，待办写明任务、责任人、完成时间。会前确认主持稿只代表可导出该稿 TXT，不代表已有正式会议纪要。

会后转换时：
- “会前情况”改为结果，现场记录整理成结论；上周任务的补充要求可统一放在该节“追问及建议”。
- 成果、本周重点仅保留会上同步或用户确认的内容，压短并保留版本号；无内容的风险和决策整行删除。
- 上下关联内容按主题合并。前文保留判断和执行要求，第六节集中列任务、责任人、时间；不重复整段任务，也不删掉必要的管理要求。
- 已有用户定稿时，以其栏目、顺序、措辞及排版为准，不恢复被删除的内容。
