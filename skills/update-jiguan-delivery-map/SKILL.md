# 更新集管交付地图

属于插件的“三、产品交付阶段”。根据集管月度《进度跟踪表》更新 5 张地图；交付版本、中间件等细节通过顶部链接查看。

## 页面与数据范围

- 页面“数据源”固定指向 `https://365.kdocs.cn/l/cvBe6WVLHm9Q`，显示为可点击的在线文档名称，不显示本地 Excel 文件名。用户每次从该文档取得最新表格后提供，更新使用用户本次提供的文件，不自动抓取在线内容。
- 地图数据只取月度《进度跟踪表》和既有调度体系地理骨架。核对实际文件名、表头、工作表和月份。
- 不读取《集管信息一览表》，不生成环境清单、环境统计、筛选、缺项提示或导出。原始 Excel 保留在业务目录。
- 顶部保留链接“交付版本、中间件等细节”，地址为 `https://365.kdocs.cn/l/cvBe6WVLHm9Q`。使用新标签打开（`target="_blank"`、`rel="noopener noreferrer"`）。无需读取或复制链接中的文档内容。
- 保留合并、超高压、分部、省调、地调 5 个视图，以及地图统计、下钻和排除区域。地图沿用既有三色规则。

## 更新流程

1. 读取工作区、产品目录规则与 [references/workflow.md](references/workflow.md)。检查 Git 状态，修改前保留可回退提交。源表不修改。
2. 核对月度表项目键“地区 / 客户”、交付阶段和状态。新项目复用已核对的地理行；更名写回原行。一个项目可能映射到多个调度行，不能误判为重复项目，也不能删除这些映射。缺列、重复项目键、未登记落点或落点被占用时先处理，再写入。
3. 运行产品目录中的 `apply_monthly_update.py`，更新派生工作簿，再运行 `update_map.py --date YYYY-MM`。检查进度月份和固定数据源链接。
4. 检查模板和生成 HTML，确认顶部链接存在，且没有环境表数据或已移除的环境明细区块。模板修改必须写入生成脚本，避免重建时恢复旧内容。
5. 核对源表项目数、地图去重项目数、各调度层级阶段与状态。浏览器检查 5 张地图、下钻与返回、顶部链接地址和新标签打开方式，并检查运行错误。相同输入重复构建应保持结果一致。
6. 按用户授权同步内部预览站，只发布集管页面。读取实际线上内容核验哈希；网络不可用时保留当前版本的待发布提交，明确尚未上线，不能发布已被用户否决的旧版本。

## 交付

提供可点击的地图链接，简述进度月份和变化。版本、中间件等细节指向用户指定文档，不在回复中另行盘点环境表。插件只保存更新规则；原始表格和地图留在业务目录及已授权内网。
